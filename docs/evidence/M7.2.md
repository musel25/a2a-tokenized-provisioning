- **Date:** 2026-08-10
- **Time spent:** ~1 session
- **Commit(s):** see `M7.2` in the log

The slice closes the asymmetry the paper had to disclose: bandwidth carried evidence
past the config plane (the 48 Mbit/s plateau), telemetry stopped at "the config is on
the router". It stopped there for a reason nobody had checked — the config could not
have exported anything.

## Surprises / deviations from the plan

- **ADR-008 said the ordering assertion belonged in the shared contract suite.** It does
  not: delete order is invisible at the port, and `MockProvisioner` has no delete list to
  order. Forcing it there would have meant inventing mock state that models nothing —
  a rule-7 violation dressed as compliance. It is a gNMI-only unit test instead, and the
  shared suite got the assertion it *can* hold honestly: "applied" now means both nodes.
- **TLS points in opposite directions on the two hops**, which cost the most debugging.
  The tunnel transport must be plaintext (a TLS listener meets SR Linux's plaintext dial
  with `UNAVAILABLE: Socket closed`); the gNMI session inside it must be TLS (a plaintext
  client meets the router's grpc-server with `error reading server preface: EOF`). Both
  failures look like "the collector is broken".
- **The stale `a2a-ent8-a1` destination ADR-008 flagged is explained, not a rule-8
  violation.** The destination-only code path left the inert half behind because
  teardown never looked for tunnels. Nothing was wrong with idempotence.
- **The canonical `collector_endpoint` was left alone** (`10.0.0.50:57000`). Pointing it
  at the lab collector would make every e2e telemetry lifecycle deliver samples, but it
  leaks lab topology into a story address quoted in 10 places. Delivery is once-established
  evidence instead — exactly the structure the bandwidth plateau already uses, where the
  per-run claim is also config-only.
- **The dashboard was reporting `"oper": "up"` as a literal.** Now that the router has a
  real opinion, it reports the router's. On the stock story fixture that reads
  "dialling", which is true and more informative than the constant was.
